## Travel Planner

This project was developed as part of the Next Level Week (NLW) challenge by Rocketseat. It is a **travel planner** designed to help you organize your trips efficiently.

## Technologies Used
- **React**: For building the interactive and dynamic interface.
- **Tailwind CSS**: For styling and responsiveness.

## Features
- Organize your trip by adding necessary details.
- Add destinations, dates, and activities.
